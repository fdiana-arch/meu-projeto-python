# Atividade Prática - Python

Este projeto consiste em um script automatizado em Python desenvolvido para demonstrar a lógica de cálculo de médias escolares e boas práticas de documentação.

## ⚙️ O que o código faz
O script possui notas escolares pré-definidas, calcula automaticamente a média aritmética entre elas e exibe o status final do aluno (Aprovado ou Reprovado).

## 🚀 Como Executar o Projeto
1. Certifique-se de ter o Python 3 instalado em sua máquina.
2. Abra o terminal ou prompt de comando na pasta do projeto.
3. Execute o script com o seguinte comando: `python script.py`
